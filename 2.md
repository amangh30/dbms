## Relational Division

Given a division operation:

```

A(X, Y) ÷ B(Y)

```

### Result
- The result contains only attributes **X**  
  (i.e., the attributes present in `A` but not in `B`)

### Meaning
- It returns all values of **x** such that:

```

For every y ∈ B, the tuple (x, y) exists in A

```

### Intuition
- Find all `x` values that are related to **every** `y` in relation `B`.

### Example (Conceptual)

If:
- `A` represents `(Student, Course)`
- `B` represents `(Course)`

Then:
```

A ÷ B

```

returns:

> All students who are enrolled in **every course listed in B**
```
